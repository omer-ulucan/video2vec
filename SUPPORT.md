# Support

This is an interim policy for the 0.x series; the full support policy (supported versions, release cadence and fix windows) is published with v0.8.0.

## Getting help

- **Questions and documentation problems:** open an issue with the *Documentation or question* form.
- **Bugs:** open an issue with the *Bug report* form and include the version, environment and a reproducer.
- **Feature requests:** use the *Feature request* form.
- **Security vulnerabilities:** never in public; follow [SECURITY.md](SECURITY.md).

## Supported versions

During 0.x only the latest release receives fixes. Upgrade to the latest release before reporting a bug.

## Expectations

video2vec is maintained by one person. Issues are triaged regularly, but there is no guaranteed response time and no commercial support.
